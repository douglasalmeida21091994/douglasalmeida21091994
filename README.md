### Sobre mim

Trabalho com desenvolvimento full stack em sistemas que não podem parar. Hoje sou o responsável técnico pelo produto na **Smile Saúde**, onde cuido de arquitetura, integrações e do dia a dia de um sistema clínico que roda mais de 700 atendimentos por dia — agenda, prontuário, faturamento e autorizações, tudo em produção o tempo inteiro.

Fora isso, mantenho projetos para a <a href="https://mracademy.com.br" target="_blank"><strong>MedCore Academy</strong></a>, cuidando de tudo: banco de dados, autenticação, pagamentos, deploy.

Gosto de entender o problema antes de sair escrevendo código — geralmente isso poupa retrabalho depois.

**Portfólio:** [douglasalmeidadev.com.br](https://douglasalmeidadev.com.br)
